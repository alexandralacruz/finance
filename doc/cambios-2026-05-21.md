# Cambios - Presupuesto Mensual v2
## 2026-05-21

---

## Resumen

Reescritura completa de la sección de Presupuesto. Se pasa de una vista simple de límites de gasto con barras de progreso a una vista completa de dos columnas (Gastos | Ganancias) con previsto, real, diferencia, sistema de ahorro 80/20, notificaciones y categorías dinámicas.

---

## Backend

### `app/models/orm.py`
- **Entity**: añadido campo `is_primary_income` (Boolean, default=False). Permite marcar una entidad como cuenta principal de ingresos fijos.
- **Category** (nueva tabla): `id, name, type (expense|income), active, sort_order, created_at`. Categorías dinámicas con soft-delete.
- **Transaction**: añadido `category_id` (FK → categories.id, nullable). Relación `category_rel`.
- **Budget**: añadido `category_id` (FK → categories.id, nullable). Relación `category_rel`.

### `app/migrate_v2.py`
Script de migración que:
1. Añade columnas nuevas (`is_primary_income`, `category_id`, `sort_order`) a tablas existentes
2. Crea la tabla `categories`
3. Inserta 19 categorías seed (14 expense + 5 income) en el orden del mockup original
4. Mapeo inteligente: transacciones con "NOMI" → Sueldo, con "INTERESES" → Intereses
5. Vincula transacciones y budgets existentes a categorías por coincidencia de nombre
6. Marca BC como cuenta principal de ingresos si no hay otra

### `app/api/routes/budgets.py`
- **`GET /budgets/{year}/{month}/full`** — Endpoint principal. Devuelve:
  - `primary_entity`, `saldo_inicial` (balance BC al inicio del mes)
  - `saldo_final` (= inicial + ganancias reales - gastos reales)
  - `ahorro_mes`, `ahorro_acumulado`, split 80/20 (`ahorro_acumulado_80`, `ahorro_acumulado_20`)
  - `ahorro_mes_anterior`, `ahorro_variacion_pct` (% vs mes anterior)
  - `ahorro_pct_ingresos` (% ahorrado sobre ingresos)
  - `notificacion`, `notificacion_tipo` (felicitacion | bien | advertencia | alarma)
  - `ganancias`: `previsto_total`, `real_total`, `diferencia_total`, `categorias[]` (nombre, previsto, real, diferencia)
  - `gastos`: `previsto_total`, `real_total`, `diferencia_total`, `categorias[]` (nombre, previsto, real, diferencia, editable)
- **`GET /categories`** — Listar categorías activas (filtro opcional por tipo)
- **`POST /categories`** — Crear/reactivar categoría
- **`DELETE /categories/{id}`** — Soft-delete de categoría
- **`POST /budgets`** — Actualizado para aceptar `category_id`
- **`DELETE /budgets/{id}`** — Eliminar límite de presupuesto
- **`GET /budgets/{year}/{month}/status`** — Legacy, conservado

### `app/api/routes/entities.py`
- **`PUT /entities/{id}/set-primary-income`** — Marca esta entidad como cuenta principal de ingresos y desmarca las demás.

## Frontend

### `src/ui/views/BudgetView.vue`
Reescritura completa (520 líneas):

**Layout:**
- Selector mes/año + botón "Ver presupuesto"
- Card de Saldo inicial (auto-calculado, badge "auto")
- Banner de notificación con color según estado (verde/azul/amarillo/rojo) + ícono (🎉/✅/⚠️/🔴)
- Barra visual 80/20 del ahorro acumulado
- Cards Saldo Inicial / Saldo Final
- Dos columnas responsive (desktop: lado a lado, móvil: stacked)

**Tabla de Gastos (columna izquierda):**
- Totales: Previsto | Real | Difer.
- Filas por categoría con inline editing: clic en celda Previsto → input numérico → blur/enter guarda vía API
- Las categorías con gasto real > previsto se resaltan en rojo suave
- Botón × para eliminar categoría (soft-delete)
- Input + botón para añadir nueva categoría de gasto

**Tabla de Ganancias (columna derecha):**
- Totales: Previsto | Real | Difer.
- Previsto = suma de nóminas del mes más reciente con "NOMI" en BC (100% asignado a "Sueldo")
- Si no hay nómina, la celda de Sueldo es editable manualmente
- Resto de categorías de ingreso con Previsto = 0
- Botón × para eliminar + input para añadir categoría

**Notificaciones:**
- 🎉 Felicitación: ahorro mensual ≥ 20% de los ingresos
- ✅ Vas bien: ahorro mensual > 0
- ⚠️ Advertencia: déficit pero dentro del colchón 20%
- 🔴 Alarma: déficit consume el 80% bloqueado

## Reglas de negocio

| Concepto | Cálculo |
|----------|---------|
| Saldo inicial | Balance de la cuenta principal al inicio del mes (último `balance` antes del día 1) |
| Ganancias Previsto | Suma de transacciones con "NOMI" en descripción del mes más reciente que tenga nómina |
| Ganancias Real | Suma de ingresos reales del mes en la cuenta principal |
| Gastos Previsto | Suma de `Budget.limit_amount` del mes |
| Gastos Real | Suma de egresos reales del mes en la cuenta principal |
| Saldo Final | Saldo Inicial + Ganancias Real - Gastos Real |
| Ahorro mensual | Ganancias Real - Gastos Real |
| Ahorro acumulado | Saldo actual de la cuenta principal |
| 80% bloqueado | Ahorro acumulado × 0.80 |
| 20% colchón | Ahorro acumulado × 0.20 |
| Variación % | (Ahorro mes - Ahorro mes anterior) / |Ahorro mes anterior| × 100 |
